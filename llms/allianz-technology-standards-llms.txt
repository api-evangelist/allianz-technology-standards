# Allianz Technology Standards

> A collection of technology standards and guidelines maintained by Allianz for software development, API design, architecture, and engineering practices. Allianz follows API-first development using OpenAPI specifications, Backend for Frontends (BFF) architecture, and standardized patterns for pagination, sorting, webhooks, and asynchronous processing. This llms.txt was generated by API Evangelist from the catalog index (method: generated) — Allianz does not publish an llms.txt.

## APIs

- [Allianz Trade API Design Standards](https://developers.allianz-trade.com/docs/api-design-guidelines): REST API conventions, pagination (pageSize, page, totalRequired), sorting, async JobID processing, webhook patterns, and OAuth2 security.
- [Allianz Backend Development Standards](https://globaldigitalfactory.allianz.com/blog/finally-talking-about-backend-.html): Allianz Global Digital Factory backend standards — Java/Kotlin, Spring Boot microservices, API-first with OpenAPI, and Backend for Frontends architecture.
